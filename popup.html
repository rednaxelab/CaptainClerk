CaptainClerk Keybindings

One-stop reference. Grouped by feature.

Clerk

Grid tables (paste/copy dropdowns, selects, and autocomplete-aware fields)

⌘/Ctrl Shift V Paste dataHonors dropdowns, selects, autocomplete
⌘/Ctrl Shift C Copy dataHonors dropdowns, selects, autocomplete
Alt Shift End Clear grid of inputs
Alt Shift Delete Delete rows until empty
Alt Delete Delete active row

Clerk Tabs

Single input value repeated across multiple tabs

⌘/Ctrl Shift ↓ Move to next tab
⌘/Ctrl Shift ↑ Move to previous tab
Alt Shift V Paste to tabs, ignore zerosStarts at tab #1
Alt Shift Z Paste to tabs, enforce zerosStarts at tab #1
Alt Shift . (>) Paste to tabs, ignore zerosStarts at the CURRENT tab
Alt Shift / (?) Paste to tabs, enforce zerosStarts at the CURRENT tab
Alt Shift S Sum all tab values
Alt Shift 0 Clear all tabs
Alt Shift L Copy full tab/form list to clipboard
Alt Shift C Copy all tab values (backward)For reconciliation

Captain

⌘/Ctrl Shift L Toggle sidebar + single-page mode
PageDown Next pageOnly while single-page mode is active
PageUp Previous pageOnly while single-page mode is active
Home Jump to first pageOnly while single-page mode is active
End Jump to last pageOnly while single-page mode is active
Alt Shift 1-9 Jump to page # directlyNo-op if that page doesn't exist · only while single-page mode is active
